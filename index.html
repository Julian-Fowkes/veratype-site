HOW IT WORKS

Three steps. No disruption.

Students write normally. You get a score. Nobody's workflow changes.

01

Students install the extension

One click from the Chrome Web Store, register with an email, done. It turns on automatically in Google Docs and Word Online.

02

They write. We measure behaviour.

Typing rhythm, paste frequency, editing patterns, session duration — 19 signals scored in the background. We measure how the document was produced, not what it says.

03

You get a clear signal

Each session is scored: Authentic, Questionable, or Inauthentic. You decide what to do with it: a score is a reason to look, not a verdict.

FEATURES

What it does.
What it doesn't.

The short version: we see timing and patterns. We never see content.

We never see the words

Not a character. Not a sentence. We store key categories ("alphabetic key"), the timing between keys, a per-session rhythm summary under one-way hashes, and paste counts. The actual writing never leaves the browser.

19 signals, personalised baselines

Paste ratio, typing rhythm, editing distribution, and more. Scoring adapts to each student's own patterns over time — so fast typists aren't penalised for being fast. Telemetry from each install is signed.

Paste detection

An essay typed over an hour looks nothing like one assembled from 7 paste events in 3 minutes. We track paste count, size, and timing.

Three tiers, not pass/fail

Authentic, Questionable, or Inauthentic. The middle tier is there because ambiguity is real — you decide whether to follow up.

Google Docs & Word Online

Works in both. Google Workspace schools, Microsoft 365 schools, mixed environments — one extension covers it.

Students don't think about it

Register once, enter a class code, forget it exists. The extension runs silently in the background. No pop-ups, no interruptions during writing.

FAQ

Frequently asked questions

Quick answers to the questions we hear most.

Does Veratype read what students type?
No. Veratype never stores or reads student writing. It analyzes behavioural patterns — keystroke timing, paste events, editing flow. Typing rhythm for common key pairs is kept only as a per-session summary under one-way hashes — how often and how fast, in no order. The actual words never leave the browser.
Does Veratype detect AI-generated writing?
No, and it does not try to. Veratype shows how a document was produced: it scores 19 behavioural signals such as paste ratio, typing rhythm, editing distribution and session duration. A score is a reason to have a conversation, not proof of anything. Telemetry from each install is signed, so it cannot be altered on the way or submitted by someone else.
Can Veratype tell if a student used ChatGPT?
Not directly, and it does not claim to. Veratype is not an AI detector: it cannot see which tools a student has open, and it never reads what the text says. What it shows is how the text arrived in the document. Writing that is typed and revised over several sittings looks different from text that arrives in a few large pastes, or faster than a person can type. That difference is where a conversation with the student can start.
Does Veratype detect copy and paste?
Yes. It counts each paste and how many characters it brought in, and it tells apart text moved around inside the document from text brought in from somewhere else. It never sees what was pasted.
How is Veratype different from Google Docs version history?
Version history shows what a document said at each point, one document at a time, and someone has to read through it. Veratype gives each document a score and a short list of reasons, for a whole class at once, without anyone reading the text. The score can tell you which version histories are worth opening.
Can a Veratype score be wrong?
Yes. A score is an indicator, not evidence. A student who pastes in their own notes, or types up a handwritten draft, can produce a session that looks unusual. That is why Veratype shows the reasons behind every score, and why any academic decision has to be made by a person. Educators can also record an assistive-input accommodation for a student, so that signals which assume typed keys are left out.
What platforms does Veratype support?
Veratype works in Google Docs and Word Online (including word.office.com, word.cloud.microsoft, SharePoint, and OneDrive) via a free Chrome extension.
